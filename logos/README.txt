팀 로고 넣는 곳
===============

이 폴더에 <팀태그>.png 파일을 넣으면 사이트 순위표에 자동으로 표시됩니다.
파일이 없는 팀은 팀 색깔 뱃지로 대신 표시됩니다.

  · 파일명 = config/teams.json 의 팀 태그  (대소문자 구분 안 함)
  · 확장자 = png, jpg, webp, svg, gif
  · 권장 크기 = 64x64 이상 정사각형, 배경 투명 png

지금 대회(GOTF 2026) 기준 파일명 예시
  AL.png    Anyone's Legend
  17.png    17 Gaming
  TWIS.png  Twisted Minds
  GK.png    Geekay Esports
  VIT.png   Team Vitality
  GTE.png   GAM X TE
  FS.png    FaZe Clan  (실제 태그는 teams.json 확인)
  T1.png    T1
  FLC.png   Falcons
  VP.png    Virtus.pro
  MiTH.png  MiTH
  JDG.png   JD Gaming
  SE.png    Shadow Esports
  DNS.png   DN SOOPers
  DGE.png   DIGA Esports
  R8.png    R8 Esports

파일을 넣은 뒤 4_사이트만들기.bat (또는 5_공개하기.bat) 을 한 번 실행하면 반영됩니다.

주의: 팀 로고는 각 구단의 상표입니다. 방송·보도 목적으로 쓰실 때
      각 구단이 배포하는 공식 미디어킷의 파일을 사용해 주세요.
